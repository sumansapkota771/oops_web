# OOPS! Nepal — Admin User Guide

This guide shows OOPS! Nepal staff how to run the website from the **admin panel**.
You do not need to know how to code. If you can use Facebook or Gmail, you can use the admin.

Everything you see on the public website — headings, prices, offers, photos, videos, opening hours, FAQs — is edited here.
When you press **Save changes**, the live website updates straight away. No developer is needed.

## The 60-second version

1. Go to **your-website-address/admin** and sign in with your email and password.
2. Use the menu on the left (on a phone, the ☰ button) to choose what to edit:
   - **Pages** — the words and pictures on each page.
   - **Content** — lists of things: attractions, offers, events, gallery photos, reviews, FAQs, rules.
   - **Site** — settings, media library, enquiries, users.
3. Make your change, then press **Save changes** at the bottom of the screen.
4. Press **View on site ↗** to check it.

## Cheat sheet

| I want to… | Go to |
| --- | --- |
| Change a headline or paragraph | **Pages →** the page |
| Change a phone number, email or opening hours | **Site settings** |
| Add a new game or ride | **Content → Attractions → New attraction** |
| Add a limited-time offer | **Content → Offers → New offer** (type: *Other offer*) |
| Hide an offer without deleting it | **Content → Offers**, click the eye icon 👁 |
| Update the Powerplay recharge table | **Content → Powerplay table** |
| Add an upcoming event | **Content → Upcoming events → New upcoming event** |
| Add photos to the gallery | **Content → Gallery photos → New gallery photo** |
| Show an announcement bar at the top | **Site settings → Announcement bar** |
| Read customer messages | **Enquiries** |
| Upload a new photo or video | **Media library → Upload** |
| Give a colleague access | **Users → Add a user** (admins only) |
| Download a backup | **Enquiries → Backup all content** |

## Words used in this guide

- **Admin panel** — the private area at `/admin` where you edit the site.
- **Public site / website** — what customers see.
- **Item** — one entry in a list, e.g. one attraction or one FAQ question.
- **Visible / hidden** — a hidden item stays in the admin but is not shown to customers.
- **Slug / page address** — the last part of a web address, e.g. `zipline` in `/attractions/zipline`. It is made for you automatically.
- **Alt text** — a short description of a photo, read aloud to people who cannot see it and used by Google.
- **Eyebrow** — the small tag above a heading.
